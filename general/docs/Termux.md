<h1 align="center"> Termux Commands </h1>

- Update a package
```bash
pkg update
```

- Upgrade a package
```bash
pkg upgrade
```

- Update & upgrade a package
```bash
pkg update && pkg upgrade
```

-Enable Storage
```bash
termux-setup-storage
```

- Install ffmpeg package
```bash
pkg install python ffmpeg
```

- Install yt-dlp package
```bash
pip install -U "yt-dlp[default]"
```
